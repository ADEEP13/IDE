# Changelog

## 0.1.0 - Initial release

- Browser-based MicroPython development for Vicharak Shrike boards over Web Serial.
- CodeMirror editor with project files, tabs, autosave, import, and ZIP download.
- Device filesystem browsing, editing, upload, download, creation, deletion, and project sync.
- Run, stop, soft reset, streamed terminal output, and configurable timeout/fresh-state settings.
- Multi-device selection and switching between authorised Web Serial boards.
- FPGA compatibility checks, bitstream upload, and `shrike.flash()` support.
- Firmware build detection, download, and placement under `/firmware`.
- Dark-mode-first VS Code-style interface with optional light theme.
